# 📰 AI-Powered News Intelligence Dashboard

Enterprise-grade NLP and Machine Learning platform for News Intelligence, Fake News Detection, Sentiment Analytics, and Trend Forecasting.

---

## Features

### Executive Dashboard

- KPI Monitoring
- News Distribution
- Dataset Analytics

### News Intelligence Center

- Keyword Search
- News Filtering
- Word Cloud Analysis

### Sentiment Analytics

- Sentiment Scoring
- Trend Monitoring
- Sentiment Distribution

### Fake News Detection

- AI Classification
- Confidence Scores
- Article Analysis

### Trend Forecasting

- Trending Keywords
- Topic Discovery
- Emerging Trends

### Reports Center

- CSV Export
- Executive Insights
- Intelligence Reports

## Installation

```bash
pip install -r requirements.txt
```

Train model:

```bash
python train_model.py
```

Run application:

```bash
streamlit run app.py
```
